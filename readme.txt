После создания класса есть 2 метода
Все переписки пользователей сохраняются

1) add_question - Добавляет вопрос в переписку с lm и возращает ответ
2) clear_chat_user - Очищает чат юзера, принимает в себя особые параметры
    2.1) clear_chat_user(number=0) - Очищает по номеру в списке включая ответ ии
    2.2) clear_chat_user(question="") - Очищает конкрентный вопрос пользователя включая ответ ии

Пример использования
matve = User_chat_Ollama() # Создаем обьект калла
matve.add_question("Сколько время? ") #  добавляем вопрос
matve.add_question("Сколько время в мск ") # добавляем вопрос
matve.clear_chat_user(question='Сколько время в мск ') # Удаляем по вопросу
matve.clear_chat_user(number=0) # Удаляем по номеру в списке
matve.clear_chat_user() # Очищаем весь чат
print(matve) # Печает весь список вопрос включая ответы от lm и вопросы от юзера
